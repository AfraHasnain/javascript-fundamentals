Question 3: Temperature Checker
Take the temperature from the user.
- If the temperature is 0°C or below, print "Freezing".
- Otherwise, print "Not freezing".

Ans: let temp = prompt("Enter Temperature");
if (temp <= 0) { console.log("Freezing"); }
else { console.log("Not freezing"); }



Question 4: Age Category
Take the user's age and display the appropriate category:
- 0-12: Child
- 13-19: Teenager
- 20-59: Adult
- 60 and above: Senior Citizen

Ans: let age = prompt("Enter Your Age");
if (age >= 0 && age <= 12) { console.log("Child"); }
else if (age >= 13 && age <= 19) { console.log("Teenager"); }
else if (age >= 20 && age <= 59) { console.log("Adult"); }
else { console.log("Senior Citizen"); }



Question 5: Electricity Bill Calculator
Take the number of electricity units consumed and calculate the bill using these rates:
- First 100 units: Rs. 10 per unit
- Next 100 units: Rs. 15 per unit
- Above 200 units: Rs. 20 per unit
Calculate the bill using cumulative rates. For example, the first 100 units are charged at Rs. 10 each, and only the units above 100 are charged at the next rate.

Ans: let units = prompt("Enter Units"); let bill = 0;
if (units <= 100) { bill = units * 10; }
else if (units <= 200) { bill = 100 * 10 + (units - 100) * 15; }
else { bill = 100 * 10 + 100 * 15 + (units - 200) * 20; }
console.log(bill);
